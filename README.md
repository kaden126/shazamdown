# `shazamdown`
Convert documents, presentations, spreadsheets, and more to markdown files.

## Introduction
`shazamdown` is a tool for converting commonly used rich-text files into markdown, which makes them take up less space, and be easier to edit by hand.

The app features an intuitive ui, built with the [slint](https://github.com/slint-ui/slint) gui toolkit, and the rust programming language. Simply type the path to the input file, or open it with your file explorer, and do the same for the destination file.

## Installation
`shazamdown` is early, active development, but you can get prebuilt binaries and installers for linux (x64) and windows (x64) from the releases.

I hope you enjoy it!
